# HR-сессия · Газпром недра

Статический сайт: HTML, CSS, JavaScript. Сервер, база данных и сборка не требуются.

## Архитектура HR-сессии

- index.html — главная HR-сессии: четыре направления и общий указатель материалов.
- strategy.html — самостоятельный раздел стратегии 2027–2030, основанный на презентации.
- culture.html — место для самостоятельных материалов по корпоративной культуре.
- kedo.html — место для КЭДО.
- learning.html — место для обучения и развития персонала.

В трёх подготовленных разделах есть отдельные области для текстов и документов.
Они явно обозначены как ожидающие материалов. Форм загрузки и сохранения нет.
На странице культуры есть ссылка на уже имеющиеся показатели в разделе стратегии.
Основной источник раздела стратегии — презентация PDF. Протокол дополняет её поручениями.
Миссия, видение, цель, ценности, состав ставок и показатели берутся из презентации.
Логотип — PNG с исходной альфа-маской из документа, без фоновой плашки и CSS-фильтров.

## Публикация на GitHub Pages

1. Загрузите папку `docs` из архива и этот README в репозиторий GitHub.
2. Откройте Settings → Pages → Build and deployment.
3. Выберите Deploy from a branch, ветку main и папку /docs. Нажмите Save.
4. Дождитесь завершения публикации. Адрес появится в разделе Pages.

Все пути относительные: сайт работает и в корне домена, и в подпапке репозитория.
Публикация на GitHub Pages меняет доступность материалов в соответствии с настройками вашего репозитория и Pages.

## Содержание и редактирование

- `docs/index.html` — главная HR-сессии.
- `docs/strategy.html` — тексты раздела стратегии.
- `docs/culture.html`, `docs/kedo.html`, `docs/learning.html` — подготовленные страницы направлений.
- `docs/styles.css` — оформление и адаптация экранов.
- `docs/content.js` — ставки, 17 ключевых показателей, 18 дополнительных и 11 поручений.
- `docs/app.js` — поиск, фильтры, вкладки, навигация.
- `docs/assets` — исходные документы, фирменный логотип и локальный шрифт.

Добавляйте тексты и документы на соответствующую страницу направления, сохраняя смысловую разметку и существующие CSS-классы. При появлении материалов обновляйте статус направления на главной.
После изменения текста проверьте локальные ссылки и поиск. Если добавляется новая тема, включите её в `searchIndex` в app.js.

## Шрифт

Основной шрифт в CSS — Arial Narrow. Он используется, если установлен на устройстве.
Файл Arial Narrow не предоставлен и не включён в поставку. Для устройств без него локально
подключён Roboto Condensed (OFL), чтобы сохранить узкие пропорции и поддержку кириллицы.
Для единого Arial Narrow на всех устройствах замените fallback лицензированным веб-файлом этого шрифта.
Лицензия резервного шрифта: docs/assets/FONT-LICENSE.txt.

## Источники содержания

Приложение «Стратегия развития Общества на 2027–2030 годы», октябрь 2026 (10 страниц),
и протокол стратегической сессии 8–9 октября 2026, Санкт-Петербург.
Реквизиты приказа в приложении не заполнены. Сайт не подтверждает утверждение стратегии.
Статус исполнения поручений не предоставлен; сроки не означают выполнение.
Перечень приложения содержит четыре ставки и две опции, протокол — пять обсуждавшихся ставок.
Значения показателей — плановые ориентиры, а не текущая аналитика.

## Дизайн и проверка

Основные цвета #0079C2 и #FFFFFF, дополнительные — тёмно-синий и нейтральные тона.
Без теней. Смысловая HTML-разметка, native details/dialog, клавиатурная навигация,
видимый фокус, учёт prefers-reduced-motion, крупные мобильные области нажатия.
Декоративные геологические контуры не изображают фактические геологические данные.
КЭДО и обучение обозначены как ожидающие материалов.
